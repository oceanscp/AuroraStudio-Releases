# Aurora Studio — releases

Installers and update files for Aurora Studio, a Windows app that downloads videos, makes them smaller, converts them for editing and separates audio on your own computer.

Download the latest installer from [Releases](https://github.com/oceanscp/AuroraStudio-Releases/releases/latest).

The installer is not code-signed, so Windows SmartScreen warns the first time: choose **More info → Run anyway**. It installs for the current user, with no administrator prompt. After that Aurora Studio keeps itself up to date from this repository's releases; `SHA256SUMS.txt` in each release lets you check the download.

This repository holds release files only.
